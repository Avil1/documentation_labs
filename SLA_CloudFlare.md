## 1. Определения

- **Коэффициент затронутых клиентов (Affected Customer Ratio)**: расчетный показатель, определяемый по формуле, приведенной в иллюстрации к данному разделу.
- **Заявка (Claim)**: требование, поданное Клиентом в компанию Cloudflare в соответствии с условиями настоящего Соглашения.
- **Плановое время простоя Клиента (Customer Planned Downtime)**: время простоя в минутах, прямо указанное Клиентом, включая время запроса на приостановку доступа к Сервису.
- **Инцидент (Incident)**: любой набор обстоятельств, приводящих к наблюдаемому или воспроизводимому ухудшению качества работы Сервиса.
- **Проблема (Issue)**: любой набор обстоятельств, приводящих к невыполнению Уровня обслуживания.
- **Ежемесячная плата (Monthly Fee)**: фактические сборы, уплаченные Клиентом в платежный месяц, предшествующий Инциденту (исключая сборы за Сервисы со Специфическим SLA).
- **Период простоя (Outage Period)**: количество минут простоя, возникших в результате Внепланового отключения Сервиса.
- **Проблема P1**: Сервис значительно нарушен или недоступен через несколько интернет-провайдеров (ISP) в нескольких географических регионах.
- **Проблема P2**: Повторяющаяся невозможность использования Сервиса через одного провайдера (локализованная проблема).
- **Проблема P3**: Несрочная проблема, не препятствующая использованию Сервиса существенным образом (минорные баги).
- **Проблема P4**: Общие вопросы, информационные запросы, предложения по улучшению функций.
- **Запланированная доступность (Scheduled Availability)**: общее количество минут в месяце за вычетом Планового времени простоя Клиента.
- **Уровни обслуживания (Service Levels)**: обязательства по уровню обслуживания из Раздела 2 и другие стандарты Cloudflare.
- **Внеплановое отключение Сервиса (Unscheduled Service Outage)**: прерывание работы Сервиса, о котором не было заранее сообщено, делающее сайты Клиента недоступными (исключая Плановый простой и Исключения из Раздела 8.1).

## 2. Обязательства по уровню обслуживания

1. **Измеримое повышение производительности**: Сервис доставляет Контент Клиента измеримо быстрее, чем без использования Cloudflare.
2. **100% времени безотказной работы**: Глобальная доступность доставки Контента Клиента 100% времени.
3. **Штрафные санкции**: При невыполнении обязательств Клиент получает Сервисный кредит (Service Credit) согласно Разделу 9 или Специфическому SLA.

---

## 3. Доступ к поддержке

- Клиент использует онлайн-интерфейс учетной записи Cloudflare для управления Сервисом.
- **Онлайн-центр поддержки** позволяет: открывать Заявки, отправлять данные для решения Проблем, проверять статус, отслеживать переписку с инженерами и получать доступ к информационным ресурсам.
- **Телефонная поддержка**: выделенная команда инженеров для сообщения и решения потенциальных Проблем.
- Дополнительная информация: [www.cloudflare.com/help](http://www.cloudflare.com/help).

---

## 4. Объем поддержки клиентов

- Включает онбординг и техническую поддержку в рамках выбранного пакета успеха (*Success Package*).
- > ⚠️ **Важно**: Поддержка **не включает** разработку кода или отладку веб-сайтов/ПО Клиента.
- По соображениям безопасности Заявки могут подавать только авторизованные пользователи Клиента.

---

## 5. Время реакции и доступность поддержки

Первоначальное время реакции зависит от пакета успеха и серьезности Заявки (отсчитывается с момента инициирования Заявки):

| Уровень проблемы | Стандартный план (Standard) | Премиальный план (Premium) |
| :--- | :---: | :---: |
| **P1 (Критический)** | < 2 часов | < 1 часа |
| **P2 (Высокий)** | < 4 часов | < 2 часов |
| **P3 (Средний)** | < 48 часов | < 24 часов |
| **P4 (Низкий)** | < 48 часов | < 24 часов |

> 💡 *Примечание:* Клиенты с датой начала подписки **до 10 ноября 2020 г.** автоматически получают время реакции Премиального плана.

### 5.2. Экстренная поддержка
- **Телефон**: доступен 24/7 только для проблем **P1**.
- **Онлайн**: доступен 24/7 для всех уровней проблем.
- **TAM Service** (Technical Account Management): первоначальный ответ на P1 в течение **30 минут**.

### 5.3. SOC Service (Центр безопасности)
Для клиентов с услугой SOC действуют следующие сроки реакции на инциденты безопасности:

| Приоритет | Время реакции | Определение для SOC |
| :--- | :---: | :--- |
| **P1** | < 30 мин | Текущая атака, Сервис значительно нарушен или недоступен. |
| **P2** | < 2 часов | Прошедшая подтвержденная атака с измеримым воздействием. |
| **P3** | < 24 часов | Предполагаемая атака (заблокирована или без заметного воздействия). |
| **P4** | < 24 часов | Все остальные эскалации безопасности. |

## 6. Закрытые запросы

Заявка считается решенной, если выполнено **одно из условий**:
- **(a)** Клиент соглашается, что Проблема решена.
- **(b)** Источник Проблемы на стороне третьей стороны (Cloudflare продолжает выступать в качестве ресурса для помощи).
- **(c)** Клиент не отвечает на запрос Cloudflare в течение **7 календарных дней** подряд.

> 🔄 *Клиент может запросить повторное открытие Заявки в любое время после закрытия, если Проблема сохраняется.*

---

## 7. Заявки на сервисные кредиты

1. **Уведомление**: Клиент должен уведомить Cloudflare об Инциденте и намерении подать Заявку в течение **5 рабочих дней** после Инцидента.
2. **Доказательства**: Заявка должна содержать подробное описание, продолжительность, трассировки сети (traceroutes), затронутые URL и предпринятые шаги по решению. Срок подачи: до конца платежного месяца, следующего за месяцем Инцидента.
3. **Проверка**: Cloudflare добросовестно проверяет Заявку на основе всех разумно доступных данных.

## 8. Исключения из SLA

SLA **не применяется** к проблемам с производительностью или доступностью, вызванным:

- **(a)** Событиями вне контроля Cloudflare:
  - Оборудование, ПО или проблемы подключения Клиента/конечных пользователей.
  - Поврежденный Контент Клиента.
  - Действия/бездействие Клиента, его сотрудников, агентов, подрядчиков или поставщиков.
  - Несанкционированный доступ третьей стороны через учетные записи/оборудование Клиента.
- **(b)** Продолжением использования Сервиса Клиентом после рекомендации Cloudflare изменить такое использование, если Клиент не последовал совету.
- **(c)** Бета-тестированием и пробными версиями сервисов (если иное не согласовано письменно).

---

## 9. Сервисные кредиты

- Размер и метод расчета указаны в Разделе 10 или в Специфическом SLA.
- Являются **единственным и исключительным** средством правовой защиты за нарушение Уровней обслуживания.
- **Лимит**: Общая сумма кредитов за годовой период не может превышать **6 месяцев** совокупных фактически уплаченных Ежемесячных плат.
- Расчет производится только на основе фиксированных Ежемесячных плат (если иное не указано в Специфическом SLA).

---

## 10. Расчет сервисных кредитов

- Для каждого Периода простоя в течение месячного платежного периода предоставляется кредит, рассчитываемый по формуле, применимой к пакету успеха Клиента *(см. иллюстрацию расчета в оригинальном документе)*.
- Для клиентов с датой начала подписки **до 10 ноября 2020 г.** всегда применяется формула расчета Премиального плана.

---

## 11. Методология

- **Мониторинг**: Cloudflare не несет ответственности за комплексный мониторинг Контента Клиента (это ответственность Клиента). Cloudflare учитывает данные, полученные с помощью коммерчески разумных независимых систем измерений Клиента.
- **Расчет коэффициента**: Cloudflare использует все разумно доступные данные (включая анализ данных сервиса непосредственно перед простоем) для оценки доли посетителей, затронутых в одном или нескольких глобальных ЦОД Cloudflare.
